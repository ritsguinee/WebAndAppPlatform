# 📍 Guide de terrain pour le recensement GPS

Guide pratique pour les agents recenseurs de la commune de Mamou.

## 🎯 Objectif

Collecter les coordonnées GPS de chaque bien immobilier lors du recensement pour permettre leur localisation sur Google Maps.

---

## 📱 Équipement nécessaire

### Option 1 : Smartphone avec GPS (Recommandé)

- **Smartphone Android ou iPhone** avec GPS activé
- **Application GPS** installée :
  - Google Maps (préinstallé sur la plupart des téléphones)
  - Maps.me (recommandé pour zones sans réseau)
  - Organic Maps (alternative gratuite)
- **Connexion internet** (optionnelle si vous utilisez Maps.me)
- **Batterie de secours** (pour longues journées)
- **Stylo et formulaire papier** (backup)

### Option 2 : GPS dédié

- GPS de randonnée (Garmin, Magellan, etc.)
- Réglé sur format décimal (DD)
- Piles de rechange

---

## 📋 Procédure de collecte GPS

### Étape 1 : Préparation avant le départ

1. **Chargez votre smartphone à 100%**
2. **Activez le GPS/localisation** dans les paramètres
3. **Téléchargez la zone hors ligne** (Google Maps ou Maps.me)
   - Ouvrez Google Maps
   - Tapez "Mamou" dans la recherche
   - Menu (☰) > Cartes hors connexion
   - Sélectionnez la zone de Mamou
4. **Vérifiez que l'heure est correcte** (important pour la précision GPS)

### Étape 2 : Sur le terrain

1. **Arrivez devant le bâtiment à recenser**
2. **Positionnez-vous devant l'entrée principale**
3. **Attendez 10-30 secondes** que le GPS se stabilise
4. **Ouvrez votre application GPS**

### Étape 3 : Relever les coordonnées

#### Avec Google Maps :

1. **Appuyez longuement** sur votre position actuelle
2. Une **épingle rouge** apparaît
3. **Glissez vers le haut** pour voir les détails
4. Les coordonnées apparaissent (ex: `10.3792, -12.0862`)
5. **Notez ces chiffres** sur votre formulaire

#### Avec Maps.me :

1. **Tapez sur le bouton "Ma position"** (icône GPS)
2. La carte centre sur votre position
3. **Appuyez sur votre position** (point bleu)
4. Les coordonnées s'affichent en haut
5. **Notez ces chiffres**

### Étape 4 : Vérification

**Vérifiez que les coordonnées sont cohérentes pour Mamou :**

✅ **Latitude correcte :** Entre 10.35° et 10.40°
✅ **Longitude correcte :** Entre -12.05° et -12.12° (ou 12.05 W et 12.12 W)

❌ Si vos coordonnées sont très différentes, recommencez la mesure.

---

## ✍️ Format de notation

### Format reçu du GPS

```
10.3792, -12.0862
```

### Format à saisir dans SNRR-Mamou

```
10.3792° N, 12.0862° W
```

### Conversion rapide

| GPS affiche | Vous saisissez |
|------------|----------------|
| `10.3792, -12.0862` | `10.3792° N, 12.0862° W` |
| `10.3801, -12.0871` | `10.3801° N, 12.0871° W` |

**Règles simples :**
1. Premier chiffre = Latitude → ajoutez `° N`
2. Deuxième chiffre (négatif) = Longitude → enlevez le `-` et ajoutez `° W`

## ⚠️ Conseils et bonnes pratiques

### ✅ À FAIRE

- **Activer le GPS** 5 minutes avant d'arriver
- **Se positionner à l'extérieur** (jamais à l'intérieur du bâtiment)
- **Attendre la stabilisation** du signal GPS (10-30 secondes)
- **Vérifier la précision** : La plupart des GPS modernes ont une précision de 5-10 mètres
- **Prendre plusieurs mesures** si vous doutez
- **Noter immédiatement** les coordonnées (risque d'oubli)
- **Vérifier les chiffres** avant de passer au prochain contribuable

### ❌ À NE PAS FAIRE

- ❌ Relever les coordonnées à l'intérieur d'un bâtiment
- ❌ Relever par temps très nuageux ou sous un toit
- ❌ Utiliser un GPS avec une batterie faible
- ❌ Copier les coordonnées d'un contribuable à un autre (même rue)
- ❌ Inventer des coordonnées
- ❌ Oublier de noter le signe négatif de la longitude

## 🔧 Résolution de problèmes

### ❌ Le GPS ne trouve pas ma position

**Causes possibles :**
- GPS désactivé dans les paramètres
- Vous êtes à l'intérieur d'un bâtiment
- Météo défavorable (orages, nuages épais)
- Téléphone défectueux

**Solutions :**
1. Allez dans Paramètres > Localisation > Mode haute précision
2. Sortez à l'extérieur
3. Attendez 1-2 minutes
4. Redémarrez l'application GPS
5. Si le problème persiste, utilisez un autre appareil

### ❌ Les coordonnées semblent incorrectes

**Vérifications :**
- Latitude entre 10.35° et 10.40° ? ✓
- Longitude entre -12.05° et -12.12° ? ✓
- Vous êtes bien dans le bon quartier ? ✓

**Si toujours incorrect :**
- Attendez que le GPS se stabilise davantage
- Vérifiez que le mode "Haute précision" est activé
- Essayez avec une autre application

### ❌ Pas de connexion internet

**Pas de problème !**
- Google Maps fonctionne hors ligne si vous avez téléchargé la carte
- Maps.me fonctionne entièrement hors ligne
- Le GPS fonctionne sans internet (satellites uniquement)

## 📊 Contrôle qualité

### Vérification en fin de journée

Avant de quitter le terrain, vérifiez que :

✅ Toutes les coordonnées GPS sont notées
✅ Le format est correct (° N, ° W)
✅ Les latitudes sont entre 10.35 et 10.40
✅ Les longitudes sont entre 12.05 W et 12.12 W
✅ Aucune coordonnée n'est identique (chaque bâtiment est unique)
✅ Les formulaires sont lisibles

### Saisie dans SNRR-Mamou

1. Retournez au bureau
2. Connectez-vous à SNRR-Mamou
3. Allez dans **Recensement**
4. Créez un nouveau contribuable
5. Remplissez tous les champs
6. **Saisissez les GPS exactement comme noté** : `10.3792° N, 12.0862° W`
7. Enregistrez
8. Vérifiez dans le module **Cartographie** que le point apparaît sur la carte
